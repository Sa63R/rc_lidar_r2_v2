# PCD 地图轴向检查与按需可视化

## Summary

- 在地图下拉栏旁增加“2D轴向检查”和“3D点云预览”两个按钮。
- 两种查看器均作为独立子进程窗口运行，不启动ROS、RViz或后台点云订阅。
- 未点击时不导入NumPy、Matplotlib、OpenCV或VTK，新增开销接近零；关闭窗口后进程退出并完全归还资源。
- 参考方向为场地图中竖直方向的 `12100 mm` 外边，左右两侧任选；只输出偏差数值，不判断是否合格，也不修改地图。

## Implementation Changes

### 主UI与进程管理

- 修改 `autostart/lidar_control_ui.py`，在地图选择栏增加两个按钮，使用当前选中PCD的绝对路径启动查看器。
- 新增 `autostart/map_inspector.py`，公开命令行：
  - `--mode 2d --map <pcd>`
  - `--mode 3d --map <pcd>`
  - `--self-test`
- 每种查看器最多运行一个实例；重复点击时提示先关闭现有窗口。
- 主UI关闭时先终止两个子进程，超时后强制结束，避免残留资源。
- 未选择地图、文件被删除、PCD损坏或没有有效XYZ点时给出明确错误，不影响主控制功能。
- 直接读取FAST-LIO生成的 `DATA binary` PCD；遇到ASCII或压缩PCD时，用现有PCL转换工具写入临时二进制文件后读取，退出时清理临时文件。

### 2D轴向检查

- 使用Matplotlib独立窗口显示等比例俯视栅格，默认按点密度的 `log(1+count)` 着色，并叠加 `map +X/+Y` 箭头、单位刻度和候选直线。
- 全图栅格单边最多1400像素，默认使用全部Z范围；提供Z最小值、最大值和重新生成按钮，用于排除地面、天花板或其他遮挡层。
- 打开后自动执行：
  1. 对密度栅格做边缘和直线段检测。
  2. 按长度、点云支持度和方向一致性对线段聚类。
  3. 将互相垂直的方向视为同一场地轴系，并默认选择最接近 `map +Y` 的方向组。
  4. 显示自动偏差值和候选线，结果标注为“全图自动估计”。
- 自动结果不满意时支持：
  - 拖框选择比赛区域并重新自动分析。
  - 点击其他候选线切换参考边。
  - 手动点击12100 mm外边的两个端点；程序在点击线附近收集栅格/点云并进行稳健直线拟合，避免直接使用鼠标坐标。
- 自动检测失败或拟合支持点不足时不输出伪造数值，保留栅格并提示框选区域或手动标边。
- 将拟合直线统一为朝向 `+Y`，计算：
  - `δ = atan2(dx, dy)`，正值表示参考边随 `+Y` 增大向 `+X` 偏移。
  - 横向偏差：`12100 mm × tan(δ)`，同时显示正负方向和绝对厘米值。
  - 建议轴向修正：将map坐标轴旋转到参考边方向，同时显示顺/逆时针描述和ROS正角为逆时针的角度值。
- 结果面板显示角度、12.1米偏差、建议yaw修正、来源（全图/ROI/候选/手动）、拟合长度和残差；不显示合格、警告或不合格，也不保存或应用修正。

### 3D点云预览

- 使用VTK独立窗口，启动后才解析PCD；有限点超过12万个时采用固定随机种子的均匀采样，保证重复打开显示一致。
- 默认按Z高度着色，可切换强度着色；提供点大小、俯视、侧视、恢复视角、聚焦主体和显示全图。
- 显示 `map X/Y/Z` 坐标轴，支持鼠标旋转、缩放和平移。
- 不订阅实时点云；窗口标题明确显示当前PCD文件名。
- 关闭窗口立即退出子进程，释放源点云、采样数据、VTK对象和库内存。

## Test Plan

- `map_inspector.py --self-test`覆盖PCD头解析、二进制XYZ读取、无效点过滤、反向选线角度不变、正负角方向和12.1米偏差公式。
- 使用带旋转矩形和杂点的合成栅格验证自动方向聚类，并确认默认选择最接近 `map +Y` 的方向组。
- 验证损坏PCD、空PCD、缺少XYZ字段、转换工具失败和自动检测无候选时的错误路径。
- 扩展主UI自检，验证查看器命令构造、无地图时禁止启动和单实例状态管理。
- 在最大实地图（约68.6万点）上手工验收：
  - 主UI启动时没有新增查看器进程或相关重型库开销。
  - 2D能先给全图自动结果，并可通过ROI、候选切换和手动标边修正。
  - 3D交互流畅且最多显示12万点。
  - 关闭查看器和主UI后不存在残留子进程。
  - 建图、保存地图、重定位和CAN相关原功能不受影响。

## Assumptions and Defaults

- 目标参考边是CAD图竖直方向的12100 mm外边，左右任意一边均可。
- 建图初始朝向与目标方向误差小于45°，因此全图自动结果默认选最接近 `map +Y` 的正交方向。
- 3D仅查看下拉栏选中的已保存PCD，不显示实时点云。
- yaw修正只作为提示，不旋转PCD、不写配置、不改变TF或重定位参数。
