# 删除 `fastlio_world_init` 包和 TF Compare 调试功能

## Summary
`fastlio_world_init` 不参与当前主重定位逻辑。生产链路仍是 FAST-LIO、`lidar_map_localization`、`lidar_localization`、`my_static_tf`、CANFD。
删除后会移除旧 `world` 初始化、`/tf_compare/...` PlotJuggler 调试话题和旋转外参标定入口，但不影响 `MAP_LOCALIZER` 的 PCD 匹配、`/map_lidar/odom`、`/robot/pose`、`/robot/pose_continuous`。

## Key Changes
- 删除 `src/fastlio_world_init` 整个 ROS 包，包括 `world_from_fastlio_init`、`robot_tf_offsets`、`lidar_tf_offset`、`rotation_extrinsic_calibrator` 和旧 PlotJuggler XML。
- 删除或停用依赖该包的 autostart 调试入口：`world_tf.sh`、`robot_tf_offsets.sh`、`lidar_tf_offset.sh`；从启动、停止、CAN 重启清理脚本中移除对应启动/等待/清理项。
- 保留 PlotJuggler 启动脚本，但移除 `/tf_compare/robot_origin_to_robot_base`、`/tf_compare/robot_origin_to_robot_base_highrate`、`/tf_compare/map_to_body` 的默认订阅和等待逻辑。
- 更新 README/迁移文档中的包列表、命令示例和调试说明，避免再提示运行 `ros2 run fastlio_world_init ...`。
- 保留你刚改的 `pose_interface_relocalization.sh`，不回退 `/Odometry` 输入改动。

## Removed Interfaces
- ROS 包：`fastlio_world_init`
- ROS executables：`world_from_fastlio_init`、`robot_tf_offsets`、`lidar_tf_offset`、`rotation_extrinsic_calibrator`
- 调试话题发布源：`/tf_compare/robot_origin_to_robot_base`、`/tf_compare/robot_origin_to_robot_base_highrate`、`/tf_compare/map_to_body`
