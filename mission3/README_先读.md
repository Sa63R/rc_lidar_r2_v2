# 任务三：固定地图原点与自动定位

版本2026-11-21 r4。正式O和方向已绑定；日常启动不清零，不要求手点地图位置。

部署完成后，在主机菜单搜索“任务三角点坐标”，或在程序目录运行bash bin/task3 run。车保持静止，等待自动地图定位和有效X/Y/yaw出现，再开始使用。关闭窗口会停止它启动的进程；重启保留正式原点。

视觉订阅/vision/state：X/Y米、yaw弧度；窗口yaw为度，逆时针为正。valid=false或超时即停用旧值。参考点是约定车架角点，Z延期。

包内包含程序、UI、地图定位组件、自动搜索源码、同一张无损压缩地图和正式原点配置。目标主机必须执行prepare-field适配路径，并编译新增组件；不要跨电脑复制build/install。

本机实际自动定位、原点绑定和静止接口已接通；另一台主机新版本与异位冷启动仍需现场确认，不宣称全场精度。physical_accuracy_verified仍false。

原r3与本版差别：run和同名菜单现在进入固定地图模式。调试旧启动清零仅用run-local，正式场地不要使用该调试入口。
