# 任务三：视觉组独立使用

先用浏览器打开 docs/00_使用说明.html。

首次安装由部署者完成一次；以后视觉组可自行启动主机、建立原点、接收坐标，不需要原开发者在场。
已编译主机更新后，在应用菜单搜索“任务三角点坐标”。终端替代入口：

```bash
bash bin/task3 run
```

它按需启动雷达与定位、打开原点/坐标UI；已有发布者会复用，不重复启动。
把正确角点投影对正式O、初始图示轴对齐场地轴后点击“建立起点并启动”，保持车静止约2秒。
有效坐标出现后即可移车。结束时先让视觉停用坐标，再关闭窗口，等退出后断电。
本窗口只停止自己启动的进程。断电/源定位重初始化后必须在正式O及规定朝向重新建立起点。

源码随包提供，右键解压即可查看；视觉接收示例tools/vision_subscriber.py。
目标主机已编译旧算法，r3增加一键启动；新入口的实车运行仍待恢复供电后确认。
ROS、SDK2与系统依赖不在包内。算法/机械参数未变，Z延期，物理精度标志仍false。
GitHub旧版本不会自动具备新入口，需使用本包更新。
