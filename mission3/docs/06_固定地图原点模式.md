# 固定地图原点与自动重定位

r4的run和同名菜单默认使用已绑定正式原点。包内包含地图定位组件、PCL全局搜索源码、同一张无损压缩地图和field_reference中的绑定来源。

prepare-field只解压同一张地图并适配本机路径，不改变正式O。生成的config/car_task3_field.yaml保存本机路径；固定reference_id不因重启变化。

自动全局候选检查多次一致性、独立扫描覆盖、三维几何支持和竞争候选，再向现有局部地图定位发送当前位姿及原始采样时间戳。不能可靠定位时保持无效，不用启动点充当零点。

UI只接受对应地图和当前LIO会话的初始化状态；源会话改变时停用旧变换。无需手点2D Pose Estimate，无需日常重新bind。

自动搜索编译依赖PCL、g++、pkg-config、nlohmann-json；ROS侧使用sensor_msgs_py。重复环境仍可能存在未发现的歧义，软件门控不等于物理精度证明。
