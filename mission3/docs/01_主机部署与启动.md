# 主机部署与启动（r4）

基线Ubuntu24.04/ROS2 Jazzy/x86_64。volleyball主机已有驱动、FAST-LIO和SDK2，更新时沿用这些组件。

新增依赖：libpcl-dev、nlohmann-json3-dev、pkg-config、g++、ros-jazzy-sensor-msgs-py。使用当前Jazzy系统Python。

旧主机从Sa63R/rc_lidar_r2_v2的mission3分支更新源码。配置/部署环境和运行数据保留，若Git报告本地修改冲突，保留修改并解决，不执行强制重置。

更新后的准备入口：prepare-field验证并解压同一张地图、生成本机绝对路径的config/car_task3_field.yaml；build-map编译vendor/lidar_map_localization和全局搜索工具；build-app更新角点程序；install-launcher更新菜单。
这些操作只安装/准备软件，不启动雷达，不重新定义正式O。首次全新主机才需build-stack及SDK2准备。

日常入口bash bin/task3 run或菜单“任务三角点坐标”：按需启动驱动和FAST-LIO，自动搜索旧地图，精配准接受后自动运行角点接口。保持车静止直到出现有效坐标，不需要手点当前位置或建立起点。

若有外部驱动/定位程序，避免重复启动。程序检查发布者和LIO会话身份；定位源重启或断流时停用旧坐标，关闭窗口再启动，固定O保持，无需把车搬回O。

退出先让视觉停用坐标，再关闭程序、等进程退出后断电。外部进程不会被本窗口强制关闭。

主机更新后的现场确认：首次运行出现有效坐标并能接收；再从明确离开O的位置重新启动，确认自动定位成功且没有把启动处清零。该确认尚未完成，不视为完整物理精度验收。

现场可复制命令在聊天中按实际主机状态逐条提供。本说明供交接与维护，不要求视觉重新安装整栈。
